# 소개 랜딩 Hero 디자인 점검 — 2026-07-13

## 점검 범위와 증거

- 대상: `/about` 첫 화면의 Hero 이미지와 핵심 소개 문구
- 캡처: `apps/web/Documents/design-audit/01-about-hero-before.png`
- 상태: 사용자가 제공한 데스크톱 캡처를 저장하고 확인함

## 단계별 결과

1. **Hero 핵심 문구 확인 — 수정 필요**
   - 캡처에서 불투명한 짙은 카드가 Hero의 왼쪽 절반을 덮어 사진과 글이 분리되어 보임.
   - 제목이 다섯 줄로 끊겨 핵심 문장의 호흡이 무거워짐.
   - 수정: 카드 배경·테두리·블러를 제거하고, 사진의 왼쪽에만 부드러운 음영을 적용. 제목에는 그림자와 더 넓은 글 영역을 적용함.

2. **본문과 CTA 확인 — 양호, 대비 보강**
   - 본문과 버튼의 위치는 명확하지만, 사진 배경에 따라 대비가 흔들릴 수 있음.
   - 수정: 본문에도 가벼운 그림자를 적용하고 흰색 대비를 강화함.

3. **모바일 Hero 확인 — 재캡처 필요**
   - 코드에서 카드 배경을 제거하고 작은 화면의 줄바꿈과 여백을 조정함.
   - 현재 환경에는 구현 후 화면을 캡처할 브라우저가 없어 실제 모바일 모양은 재확인하지 못함.

## 접근성 메모

- 사진 위 흰 글자는 배경의 밝기에 영향을 받으므로, 구현 후 실제 캡처에서 대비를 다시 확인해야 함.
- 텍스트 그림자는 보조 수단이며, 왼쪽 음영을 함께 유지해 색상 대비만으로 읽기 어려운 상태를 피함.

## 한계

- 이 문서는 사용자 제공 캡처 한 장을 근거로 한 Hero 단일 화면 점검임.
- 구현 후 브라우저 캡처와의 재비교는 현재 브라우저 캡처 도구가 없어 보류함.
