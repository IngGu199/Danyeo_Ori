# 미니게임 이미지 출처 기록

현재 7개 미니게임 카탈로그 카드는 외부 이미지 파일을 사용하지 않고 `@phosphor-icons/react` 아이콘과 CSS 색면으로 표시한다. 소개 랜딩 페이지의 대표 체험 카드는 아래 프로젝트 생성 키아트를 사용한다.

향후 실제 웹 에셋을 추가할 때는 게임 코드별 하위 폴더에 저장하고 아래 항목을 이 문서에 기록한다.

|---|---|---|---|---|---|---|---|
| 예: `sample-object.webp` | 예: `slice-object` | 원본 주소 | 저작자 | 라이선스명 | 가능/불가 | 가능/불가 | YYYY-MM-DD |

출처·라이선스·상업적 이용 가능 여부를 확인하지 못한 파일은 웹에 사용하지 않는다. 참고용 원본과 검토 중 파일은 저장소가 아닌 루트 `Documents/` 아래에 보관한다.
