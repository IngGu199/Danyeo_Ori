# 소개 랜딩 페이지 화면 폭 디자인 검증

검증일: 2026-07-13  
대상: `/about` 데스크톱 화면  
근거 이미지: `apps/web/Documents/design-audit/02-about-layout-before.png`, `apps/web/Documents/design-audit/03-korea-every-corner-reference.png`

## 전체 평가

현재 화면은 정보 구조와 가독성은 양호하지만, 1920px 화면에서 히어로·추천 카드가 모두 1180px 컨테이너 안에 들어가 좌우의 크림색 여백이 첫 화면의 약 38%를 차지한다. 이 때문에 사진 중심의 여행 서비스라기보다 중앙에 놓인 한 장의 프로모션 카드처럼 보인다. 참고 화면은 내비게이션 아래의 사진 레이어를 화면 양끝까지 사용하고, 텍스트와 기능 목록만 내부 그리드에 정렬해 화면 밀도와 몰입감을 동시에 확보한다.

## 1. 첫 화면의 가로 점유율

상태: 개선 필요 · 우선순위 P1

- 현재: 히어로 시작점과 끝점이 약 x=362~1544px에 머물러 1920px 화면 양쪽에 각각 약 360px의 비활성 여백이 남는다.
- 참고: 사진 캐러셀이 거의 전체 화면 폭을 사용해 첫 화면에서 여행 이미지가 주인공으로 보인다.
- 조치: `/about`의 히어로 사진만 전체 폭으로 확장하고, 헤드라인은 기존 1180px 콘텐츠 축에 맞춰 정렬했다.

## 2. 히어로와 추천 콘텐츠의 위계

상태: 양호하나 개선 가능 · 우선순위 P2

- 현재: 히어로와 추천 프로그램이 동일한 컨테이너 폭을 공유해 두 영역이 하나의 큰 카드처럼 읽힌다.
- 조치: 사진은 전체 폭의 감성적 무대로, 추천 프로그램은 1180px의 정보 카드로 분리했다. 추천 카드는 사진 아래에 겹쳐 배치해 시선이 체험 정보로 자연스럽게 이어지도록 유지했다.

## 3. 디자인 시스템 일관성

상태: 양호

- `DESIGN.md`의 크림 배경, 올리브 계층, 둥근 카드, 1120~1200px 본문 그리드는 유지했다.
- 외부 참고 화면의 파란색, 아이콘 스타일, 내비게이션 구조는 복제하지 않고 ‘전체 폭 사진 + 제한된 내부 그리드’ 원칙만 적용했다.

## 4. 반응형·접근성 리스크

상태: 코드 기준 확인 · 실제 기기 검증 필요

- 980px 이하에서는 히어로 카피와 추천 카드의 좌우 여백을 단계적으로 줄였다.
- 720px 이하에서는 전체 폭 사진을 유지하고 16px 본문 여백, 14px 추천 카드 여백을 적용했다.
- 이번 검증은 제공된 데스크톱 이미지와 코드 구조를 근거로 했으며, 200% 확대·키보드 탐색·실제 모바일 브라우저 화면은 별도 시각 검증이 필요하다.

## 적용 요약

1. 히어로 사진을 뷰포트 전체 폭으로 확장
2. 헤드라인을 기존 콘텐츠 그리드에 맞춰 정렬
3. 추천 프로그램 카드는 1180px 폭을 유지해 읽기 편한 정보 밀도 보존
4. 태블릿·모바일 여백과 겹침 간격을 별도 조정
