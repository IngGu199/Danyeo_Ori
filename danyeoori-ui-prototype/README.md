# 다녀오리 정적 UI 프로토타입

대한민국 구석구석의 축제 탐색·목록·달력 정보 구조와, 사용자가 제공한 채널형 게시판 스크린샷을 참고해 재해석한 정적 웹 UI입니다. 특정 사이트를 그대로 복제하지 않고 다녀오리 서비스 흐름에 맞게 구성했습니다.

## 페이지

- `index.html` — 기본 홈
- `festivals.html` — 전국 축제 목록과 필터
- `games.html` — 룰렛과 축제별 미니게임 목록
- `calendar.html` — 월별 축제 달력
- `community.html` — 축제 태그 필수 커뮤니티
- `styles.css` — 전체 반응형 스타일

## 실행

별도 설치 없이 `index.html`을 브라우저에서 열면 됩니다.

```bash
python3 -m http.server 8080
```

브라우저에서 `http://localhost:8080` 접속.

## 범위

- HTML/CSS 중심
- 복잡한 JavaScript 없음
- 룰렛, 필터, 달력 선택, 게시글 작성은 정적 UI
- 데스크톱·태블릿·모바일 반응형
- 축제 일정은 디자인 확인을 위한 예시 데이터
